# DJP Melamina

Abre `index.html` con doble clic para ver la web en tu navegador. Mantén los archivos dentro de la misma carpeta.

## Actualizar el sitio que ya tienes en GitHub

1. Descomprime el ZIP completo.
2. Abre tu repositorio y entra en **Code**. Desde allí, pulsa **Add file → Upload files** y sube `index.html`, `estilos.css`, `sitio.js` y `README.md`. Pulsa **Commit changes** para reemplazarlos.
3. En **Code**, abre la carpeta **assets** de GitHub. Desde dentro, pulsa **Add file → Upload files** y selecciona todos los archivos que están dentro de la carpeta **assets** de tu computadora. Guarda con **Commit changes**. Si falta la carpeta en GitHub, créala con **Add file → Create new file** y escribe `assets/LEEME.txt` como nombre. Guarda y entra a la carpeta.
4. Si ya activaste GitHub Pages, espera a que se publique la actualización. Si falta activarlo, abre **Settings → Pages**, elige **Deploy from a branch**, luego **main** y **/(root)**, y pulsa **Save**.
5. En **Settings → Pages**, abre **Visit site** y comprueba que aparezcan el logo, las fotos y el botón de cotización.

Los archivos que ya tenías dentro de **assets** pueden permanecer ahí. El catálogo tiene 30 modelos y usa las fotos `catalogo-*.jpg` para los productos. Las imágenes de referencia se pueden reemplazar con fotos propias conservando los nombres y actualizando los textos alternativos y pies de foto de `index.html`.

El paquete incluye una versión vectorial del logo. Para usar un archivo original en PNG, guárdalo en **assets** con el nombre `logo.png` y en `index.html` cambia las dos apariciones de `logo.svg` por `logo.png`.
